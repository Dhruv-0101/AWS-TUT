10. 🔄 "Requester Pays" Buckets — 50 GB Course Bandwidth Cost Delegation

Instructor Gaurav Sharma's Real Bandwidth Delegation Scenario:

THE BANDWIDTH COST DELEGATION PATTERN:

"Suppose I sell a 50 GB video course. Hosting 50 GB on S3 costs very little, but if 1,000 buyers download 50 GB each (50,000 GB outbound bandwidth), AWS would charge ME thousands of dollars!
Solution: Enable 'Requester Pays'!

11. 🌏 S3 Bucket Architecture & Regional Placement

Containers & Region Selection:

  1. Data in S3 is stored in top-level containers called **Buckets**.
  2. Every S3 bucket is created in a specific AWS Region (e.g., `ap-south-1` Mumbai or `us-east-1` N. Virginia).

12. ⚠️ Global Unique Bucket Naming Rule (`BucketAlreadyExists` Constraint)

The #1 S3 Golden Rule:

MUST-KNOW S3 BUCKET NAMING RULE:

Even though an S3 bucket is created in a specific region, **S3 BUCKET NAMES MUST BE GLOBALLY UNIQUE ACROSS ALL AWS ACCOUNTS WORLDWIDE IN ALL REGIONS!**
If User A creates a bucket named `my-company-backup` in N. Virginia, NO user anywhere on Earth can create a bucket named `my-company-backup` in Mumbai or any other region! AWS returns `BucketAlreadyExists` error.

13. 📄 Objects vs Files (Metadata, Keys & Object URLs)

Object Architecture:

  • Files stored in S3 are called **Objects** (up to 5 TB max per single object).
  • An Object consists of: Key (filename/path), Value (data bytes), Metadata (content-type, tags), and a unique Object URL.

16. ❓ Interview Questions

Q1. What is the global naming requirement for Amazon S3 Buckets?

S3 Bucket Names must be globally unique across all AWS accounts worldwide in all regions. No two AWS accounts on Earth can share the same S3 bucket name.

Q2. How does Amazon S3 help in building stateless web applications?

By storing user-uploaded files and media in S3 instead of local EC2 server disks, web nodes remain stateless and can be scaled, terminated, or replaced without losing application data.

Q3. What is the "Requester Pays" feature in Amazon S3?

Requester Pays shifts the network data transfer (download bandwidth) costs from the bucket owner to the requesting user's AWS account.

Q4. What is the maximum size of a single object that can be stored in Amazon S3?

The maximum size of a single object in Amazon S3 is 5 Terabytes (5 TB).

Q5. How can you minimize storage costs for multi-year regulatory data (e.g. 20-year medical records)?

By configuring S3 Lifecycle Policies to transition data from S3 Standard to S3 Standard-IA, and finally archiving to S3 Glacier Deep Archive for ultra-low storage cost.

2. ⚠️ Deep-Dive S3 Naming Rules & Syntax Violation Errors

Instructor Gaurav Sharma's Bucket Naming Rules Testing:

S3 BUCKET NAMING SYNTAX CONSTRAINTS:

  • Uppercase Characters: `Gaurav-Youtube-V1` → FAIL! Error: "Bucket name must not contain uppercase characters."

3. 🔓 The Goal — Public Read Object Access over HTTPS

4. 🛡️ Step 1 — Disabling "Block Public Access" Guardrail

7. ❌ The Common ARN Formatting Trap (`arn:aws:s3:::bucket` vs `arn:aws:s3:::bucket/*`)

CRITICAL BUCKET POLICY ERROR & FIX:

If you paste raw bucket ARN arn:aws:s3:::gaurav-youtube-v1, AWS returns "Unknown Error / Action does not apply to resource" because s3:GetObject applies to objects inside the bucket, NOT the bucket container itself!

THE MANDATORY FIX:

You MUST append /* to the bucket ARN: arn:aws:s3:::gaurav-youtube-v1/*. This explicitly targets all objects inside the bucket!

8. 📄 Valid Public Read JSON Bucket Policy Document Structure

Complete JSON Policy Code:

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicReadGetObject",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::gaurav-youtube-v1/*"
    }
  ]
}

  2. Click Save changes.

13. 🛡️ Security Risk Warning — When SHOULD Buckets be Public vs Private?

PRODUCTION SECURITY GOVERNANCE:

• **PRIVATE BUCKETS:** User database backups, customer PII, logs, financial records, and application secrets MUST ALWAYS keep *Block Public Access* enabled!

16. ❓ Interview Questions

Q1. What happens if you apply a Bucket Policy with `Action: s3:GetObject` on Resource `arn:aws:s3:::mybucket` without trailing `/*`?

AWS returns an error indicating the action does not apply to the resource. `s3:GetObject` requires object-level targeting, which is specified by appending `/*` (e.g. `arn:aws:s3:::mybucket/*`).

Q2. What two steps are required to make an S3 bucket's objects publicly readable over HTTPS?

1. Uncheck 'Block all public access' under Bucket Permissions. 2. Attach a JSON Bucket Policy granting `s3:GetObject` permission to Principal `*` on `arn:aws:s3:::bucketname/*`.

Q3. Do newly uploaded objects in a public bucket automatically become public, or do you have to configure each object individually?

Newly uploaded objects automatically inherit the bucket policy's public read permissions without needing individual object-level ACL modifications.

Q4. Which S3 bucket naming rule is violated by the name `My-Bucket-2026`?

S3 bucket names must not contain uppercase letters. `My-Bucket-2026` contains uppercase 'M' and 'B'.

Q5. What tool provided in the AWS Console helps construct valid JSON Bucket Policies?

The AWS Policy Generator.

4. 📊 System-Defined Metadata vs User-Defined Metadata

Every S3 Object maintains HTTP response headers and custom metadata attached as name-value pairs:

⚙️ System-Defined Metadata

Predefined HTTP headers managed by AWS or configured by the client:
• Content-Type (e.g. image/jpeg, video/mp4)
• Content-Disposition (e.g. inline or attachment)
• Cache-Control (e.g. max-age=3600)
• Content-Encoding (e.g. gzip)

👤 User-Defined Metadata

Custom key-value pairs stored with the object payload:
• Prefixed automatically by AWS as x-amz-meta-*
• Example: x-amz-meta-uploadedby: gaurav
• Example: x-amz-meta-department: devops
• Retained with the object until updated or overwritten.

5. 🧩 What is an ETag in Amazon S3?

Instructor Gaurav Sharma highlights the ETag (Entity Tag) property appearing in the Object Overview:

Definition: An ETag is an HTTP header returned by S3 representing an MD5 hash digest of the object's data.

• For standard single-part uploads, the ETag is the exact 128-bit MD5 checksum string (e.g. "5a38fc2834b6b6c...").
• Purpose: Used by client applications and browsers to verify file integrity and check if an object has changed without downloading the full payload.

Q1. Do real directory folders exist inside Amazon S3 buckets? Explain how AWS Console shows folders.

No. S3 is a flat key-value namespace. AWS Console parses slash delimiters (`/`) in object key strings (e.g. `courses/gaurav/photo.jpg`) and visually renders prefixes as virtual yellow folder icons.

5 GB (Gigabytes).

Q4. How can you upload a 100 GB database dump file to Amazon S3?

Q5. What is the difference between System-Defined and User-Defined Metadata in Amazon S3?

System-Defined Metadata consists of HTTP headers managed by AWS or configured by clients (like `Content-Type`), whereas User-Defined Metadata consists of custom key-value pairs stored with prefix `x-amz-meta-*`.
